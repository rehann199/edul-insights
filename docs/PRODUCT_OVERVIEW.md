# Product Overview

Edul-Insights is an academic analytics dashboard designed for schools. It provides actionable insights into student performance, attendance patterns and academic risk, enabling educators to identify at-risk students and track trends across the institution.

## Core Features

**Dashboard Overview**
A single-page application with a sidebar-driven interface. The overview displays:
- Four key performance indicators: total students, average performance, average attendance and at-risk count
- A histogram showing the distribution of student grades across the school
- A bar chart of average performance by grade level (9th-12th)
- Grade and subject filters in the sidebar that refine the Overview charts

**At-Risk Student Identification**
A dedicated table lists 131 at-risk students, selected by a rule and given a model-based risk tier. The system flags students with:
- Average performance below 60%, or
- Attendance below 80%

Each student receives a risk classification: High (prediction probability ≥0.85), Medium (≥0.6), or Watch (below 0.6). The flagged list itself comes from the rule; the tier comes from a RandomForest classifier trained on that same rule, so it mostly acts as a ranking signal.

**Monthly Trends**
A line chart of average assessment score by month across the school year.

**Student Profiles**
A sortable, filterable table of all 500 students (student ID, name, grade, gender, family income).

**Intervention Recommendations**
A table of 138 active interventions tailored to each at-risk student. Recommendations are rule-based text generated from performance and attendance thresholds, e.g. "Attendance counseling", "Motivational coaching", "Enroll in tutoring program" or "Subject-specific support".

## Data Foundation

The application operates on synthetic data generated by a Faker-based data generator, with 500 students, 25 teachers and 148,000 performance records spanning multiple academic periods. This demo build allows educators to explore the dashboard in a realistic setting without compromising privacy.

## Navigation

Navigation is the left sidebar (Overview, At-Risk Students, Performance Trends, Student Profiles, Interventions). The top bar links (Students, Performance, Analytics, Reports) are non-functional placeholders in this build.
