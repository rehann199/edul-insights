# Privacy and Source

## Data Privacy

This repository contains a portfolio build of the Edul-Insights dashboard. **All student, teacher and performance data displayed is synthetic and generated by Faker.** No real educational records, identifiable information or sensitive school data is included.

- **Synthetic Records:** 500 students, 25 teachers, 148,000 performance entries and 119,000 attendance logs are algorithmically generated and do not represent actual individuals or institutions.
- **Local Execution:** The dashboard runs locally with SQLite and uses no backend services. The page loads fonts and icons from public CDNs.
- **Demo Scenario:** The application is designed for exploration and evaluation. It does not connect to real school information systems or student records.

## Model Artifacts

Trained RandomForest models are stored as pickled objects in `saved_models/`. These models:
- Are trained on synthetic data for portfolio demonstration.
- Do not represent real predictive patterns in educational data.
- Should not be deployed to production without retraining on actual institutional data and validation by domain experts.
